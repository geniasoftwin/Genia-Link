# Genia Link web branding

These assets are derived directly from the visual language of the Genia Link landing page and are intended for repository/web presentation.

- `landing-logo.svg` — original landing-page link mark.
- `readme-hero.svg` — repository README hero artwork.

The web presentation palette follows the landing page: deep navy backgrounds with cyan/blue accents (`#19d7ff`, `#6483ff`) and the local trusted-network motif.

This folder does not replace the approved application icon assets documented in `branding/README.md`.
