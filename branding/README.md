# Genia Link branding

`GeniaLink-icon-master.png` is the approved Genia Link v0.3.1 master icon, carried unchanged into RC4.

Platform derivatives:
- Windows: `src/GeniaLink.Windows/Assets/GeniaLink.ico` and `GeniaLink.png`
- Android: `src/GeniaLink.Android/Resources/drawable-nodpi/genialink_logo.png`

The approved artwork uses one simple visual language on both platforms: a large white **G** with phone/laptop connection imagery on a deep-blue gradient. Windows ICO contains multiple embedded sizes; Android uses the same approved artwork in the adaptive launcher icon.
