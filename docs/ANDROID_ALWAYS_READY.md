# Android Always Ready — RC4 candidate

`Всегда готов к приёму` — опциональный режим для телефона, который должен оставаться доступным доверенному Genia Link на ПК даже после длительного простоя с выключенным экраном.

## Состояния

- Пользовательский переключатель хранится отдельно и по умолчанию выключен.
- Эффективный Always Ready = пользователь включил режим **и** Android реально исключил Genia Link из battery optimization.
- Системное состояние проверяется через `PowerManager.IsIgnoringBatteryOptimizations(packageName)`.
- После обновления с ранних тестовых сборок переключатель нового режима начинается с выключенного состояния, даже если системное исключение Android осталось от предыдущего теста. В таком случае окно честно показывает, что системное исключение ещё активно.

## Включение

1. Пользователь включает `Всегда готов к приёму`.
2. Если системное исключение уже есть, режим включается без дополнительных окон.
3. Иначе Genia Link запускает штатный `ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` для своего package.
4. После возврата в приложение фактическое разрешение перепроверяется. Если пользователь отказал, переключатель автоматически возвращается в выключенное состояние.

## Выключение

- Переключатель сразу выключает режим Genia Link и не открывает системные настройки автоматически.
- Android не предоставляет публичного API, позволяющего приложению молча снять уже выданное системное исключение battery optimization.
- Если исключение осталось, окно показывает отдельную кнопку `Настройки батареи Android` и объясняет, что для полного возврата обычной экономии нужно разрешить оптимизацию батареи для Genia Link.

## Безопасность и приватность

Разрешение `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` используется только после явного действия пользователя. Оно не добавляет облако, внешние серверы, аналитику или удалённый доступ. Передача остаётся локальной и использует существующий доверенный pairing Genia Link.

## Ограничение

Патч не добавляет автозапуск после полной перезагрузки Android. После reboot пользователь должен запустить Genia Link хотя бы один раз, чтобы локальная служба снова стартовала.
