# Genia Link v0.3.1 RC4 — финальный regression test

Цель: проверить основной сценарий Genia Link без добавления новых функций. Все устройства должны работать только в локальной сети, без облака и аккаунтов.

## 1. Матрица устройств

Прогнать в обе стороны для каждой доступной пары:

- Windows PC ↔ Windows laptop
- Windows PC ↔ Android 1
- Windows PC ↔ Android 2
- Windows laptop ↔ Android 1
- Windows laptop ↔ Android 2
- Android 1 ↔ Android 2

## 2. Обычная передача

Для каждой пары:

1. Отправить маленький файл.
2. Отправить 5–20 файлов разного размера.
3. Отправить один большой файл.
4. Проверить имя, размер и SHA/resume-поведение после завершения.
5. Прервать большую передачу и повторить — передача должна продолжиться через resume.

## 3. Сон / wake-on-transfer

1. Погасить экран Android и дождаться статуса «спит / нет свежего discovery».
2. Отправить файл с Windows на спящий Android.
3. Отправить файл с Android на спящий Android.
4. Перезапустить Windows Genia Link, пока Android спит, и повторить отправку через сохранённый authenticated endpoint.

## 4. «Файлы Genia Link»

Для каждой поддерживаемой пары:

1. Открыть удалённую папку Genia Link.
2. Перейти во вложенную папку и вернуться назад.
3. Обновить список.
4. Просмотреть JPG/PNG.
5. Просмотреть TXT/LOG/JSON.
6. Убедиться, что для видео/аудио встроенное воспроизведение не предлагается.
7. Выбрать один файл и скачать.
8. Выбрать несколько файлов из разных подпапок и скачать.
9. Убедиться, что они попали в локальную папку Genia Link и структура подпапок сохранена.

## 5. Pairing / переустановка

1. Проверить обычное сопряжение.
2. «Забыть» устройство и сопрячь заново.
3. На тестовом Android удалить/переустановить APK, затем сопрячь заново.
4. При совпадающем имени и новом ключе проверить предложение заменить старую запись или оставить обе.
5. Убедиться, что trust никогда не переносится только по имени/IP.

## 6. Сети

Повторить базовую отправку и remote browse в доступных сценариях:

- домашний Wi‑Fi/router;
- Android hotspot;
- несколько устройств в одном hotspot;
- смена Wi‑Fi/адреса доверенного устройства.

## 7. UI / стабильность

- Нет вылетов Android при открытии, выборе и скачивании удалённых файлов.
- Нет дублей одного и того же DeviceId.
- Старый DeviceId после переустановки остаётся отдельной trust-записью до явной замены/удаления.
- Windows remote-browser остаётся компактным; preview-панель появляется только для фото/текста.
- Android remote-browser остаётся компактным; «Просмотр» активен только для фото/текста.
- Кнопка главного меню Android отображает три ровные горизонтальные полоски в компактной рамке без тени.
- Android Share → Genia Link открывает выбор устройства без искусственной задержки; сверху видны количество/размер выбранных файлов, доступные устройства идут раньше спящих, последнее использованное устройство помечается.
- Диагностика имеет отдельный статус локальных служб, прокручиваемый моноширинный журнал и действие «Копировать».
- После запуска/смены Wi‑Fi нет циклического `Address already in use` и ежесекундного перезапуска background local services.
- Закрытие окна/диалога не останавливает фоновые local services.

## PASS

RC4 считается готовым к v0.3.1 Stable, если все основные пары передают файлы в обе стороны, sleep/wake и resume проходят, remote browse/download работает без crash, а критических security/regression ошибок нет.

## Always Ready — long-idle receive regression

1. После установки/обновления откройте Android Genia Link → меню → `Всегда готов к приёму`. Новый пользовательский переключатель должен быть выключен по умолчанию.
2. Если от предыдущей тестовой сборки в Android осталось системное исключение battery optimization, окно должно показать это отдельным текстом и кнопку `Настройки батареи Android`, но сам переключатель остаётся выключенным.
3. Включите переключатель. Если системного исключения нет, подтвердите штатный запрос Android на работу без battery optimization.
4. Вернитесь в Genia Link: переключатель должен остаться включённым только если разрешение действительно получено; главный статус — `Всегда готов к приёму`, уведомление — `Всегда готов к приёму • локальная сеть`.
5. Погасите экран, оставьте телефон в покое минимум на 30–60 минут и затем отправьте файл с доверенного ПК. Передача должна стартовать без ручного пробуждения телефона.
6. Выключите переключатель. Он должен выключиться сразу и не открывать системные настройки автоматически. Главный статус должен вернуться к `Готов к приёму`.
7. Если системное исключение Android всё ещё активно, в окне должна появиться кнопка `Настройки батареи Android`. Откройте её и разрешите оптимизацию батареи для Genia Link, затем вернитесь в приложение — предупреждение о системном исключении должно исчезнуть.
8. Перезагрузите телефон: патч не обещает автозапуск после reboot. После ручного запуска Genia Link настройки режима должны восстановиться из пользовательского состояния и фактического разрешения Android.
