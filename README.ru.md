# Genia Link

[English](README.md) · **Русский**

Genia Link — локальная система связи между доверенными устройствами для обмена файлами между Windows и Android. Основной путь передачи рассчитан на прямую работу внутри локальной сети без облачного ретранслятора.

> **Статус:** предварительная версия в активной разработке. Текущая линия разработки — **v0.3.1 RC4 / GNP/1 M2.6.x**. До стабильного релиза интерфейсы, детали протокола, упаковка и требования совместимости могут изменяться.

## Что проектируется в Genia Link

- обнаружение устройств в локальной сети;
- явное доверенное сопряжение с проверкой;
- аутентифицированная и зашифрованная передача файлов между доверенными устройствами;
- продолжение прерванных передач;
- защищённый просмотр и запрос файлов через рабочую папку Genia Link;
- учёт криптографической идентичности доверенных устройств и защита от незаметной подмены;
- защита аутентифицированных сообщений обнаружения от повторов и модификации;
- безопасная обработка путей и мест назначения принимаемых файлов;
- интеграция с Windows, включая сценарии **«Отправить»**;
- клиенты Windows и Android на общей протокольной/базовой части.

## Модель безопасности

Genia Link рассматривает идентичность устройства и состояние сопряжения как границы доверия. Ранее доверенное устройство не должно автоматически снова считаться доверенным только потому, что другой узел появился под тем же отображаемым именем. Изменение идентичности или ключей требует нового явного решения о доверии.

В проекте также применяются защитные проверки путей передачи, аутентифицированных сообщений обнаружения и управления, повторов сообщений и состояния доверенных узлов. Поведение, связанное с безопасностью, проверяется автоматизированными self-test сценариями в рабочем пакете разработки.

## Приватность и сеть

Genia Link предназначен для прямого взаимодействия устройств в локальной сети. Архитектура передачи не требует облачного сервиса Genia Link для ретрансляции пользовательских файлов.

При этом операционная система, менеджеры пакетов, GitHub, инфраструктура сертификатов или будущие дополнительные функции могут использовать Интернет независимо от протокола передачи Genia Link.

## Платформы

Текущие направления разработки:

- **Windows** — настольный клиент .NET;
- **Android** — клиент .NET for Android.

Точные требования к ОС и среде выполнения будут опубликованы вместе с публичными релизными пакетами.
